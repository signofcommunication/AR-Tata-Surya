# AR Tata Surya Mini — UTS Augmented Reality

Aplikasi AR tata surya + grafik batang 3D berbasis marker Hiro, dibangun dengan A-Frame + AR.js.

🌐 **Live demo:** https://signofcommunication.github.io/AR-Tata-Surya/

## Cara pakai

1. Buka URL live di atas via **HTTPS** (wajib agar kamera diizinkan browser).
2. Izinkan akses kamera saat diminta.
3. Arahkan kamera ke **marker Hiro** (`hiro.png` — tampilkan di layar HP lain atau print di kertas).
4. Tombol **Jeda/Putar**: menghentikan/menjalankan animasi tata surya.
5. Tombol **Mode Grafik / Mode Tata Surya**: beralih antara animasi 3D dan grafik batang 3D jarak planet ke Matahari (AU).

## Catatan

- Gunakan Chrome/Edge. Satu kamera hanya untuk satu tab dalam satu waktu.
- Isi identitas (Nama/NIM) di variabel `IDENTITAS` pada `index.html`.
